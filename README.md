# Сайт репетитора — Василенко Алевтина Викторовна

Одностраничный сайт без сборки: чистые HTML + CSS + JS.
Открывается двойным кликом по `index.html`, заливается на любой хостинг как есть.

**Живая версия:** https://mathscoolstar.ru
**Репозиторий:** https://github.com/Dendy-D/mathscoolstar

Домен привязан к GitHub Pages, сертификат HTTPS выпускается и продлевается автоматически.
Старый адрес `dendy-d.github.io/mathscoolstar` продолжает работать и redirect'ит на домен.

Чтобы обновить сайт после правок — обычный пуш, Pages пересоберётся сам за минуту:

```bash
git add -A && git commit -m "что поменяли" && git push
```

## Правовые документы

Четыре ссылки в подвале ведут на страницы в `docs/`. Текст перенесён из .docx
дословно, внизу каждой страницы — ссылка на скачивание оригинала.

| Ссылка в подвале | Страница |
|---|---|
| Политика конфиденциальности | `docs/oferta.html` |
| Договор публичной оферты | `docs/oferta.html` (тот же документ) |
| Согласие на обработку персональных данных | `docs/soglasie.html` |
| Сведения об образовательной организации | `docs/svedeniya.html` |
| Выписка из реестра лицензий | группа «Готовятся к публикации» |
| Уведомление о предоставлении лицензии | группа «Готовятся к публикации» |

**Если документ изменился** — положить новый .docx в `docs/files/` под тем же именем
(`oferta.docx`, `soglasie.docx`, `svedeniya.docx`) и пересобрать:

```bash
python3 tools/build-docs.py
```

Скрипт сам разметит заголовки, таблицы и ссылки и скопирует оригинал в `docs/files/`.

**Когда придут документы по лицензии:** собрать их тем же скриптом, а в подвале
`index.html` перенести два пункта из `<ul class="footer__list--pending">` наверх,
в основной список `footer__list--docs`, обернув в `<a href="docs/…">`. Когда список
`--pending` опустеет — удалить его вместе с подписью `<p class="footer__sublabel">`.

Если лицензия окажется не нужна (ИП без наёмных работников, ч. 2 ст. 91 ФЗ-273) —
просто удалить оба блока целиком.

## Как редактировать текст

Весь текст главной лежит прямо в `index.html` — открывается любым текстовым
редактором. Секции размечены комментариями (`<!-- ═══ ОТЗЫВЫ ═══ -->`).

**Добавить отзыв:** скопировать любой блок `<figure class="review">` целиком
и заменить внутри текст, имя и дату (даты две — видимая `03.08.2021`
и машинная `datetime="2021-08-03"`).

**Поменять цифры в блоке статистики:** атрибут `data-count` задаёт число,
`data-suffix` / `data-prefix` — знак рядом с ним.

## Что заложено внутри

- Адаптив: телефон, планшет, десктоп. На телефоне снизу появляется липкая кнопка записи.
- Кнопки записи открывают окно выбора: WhatsApp / Telegram / звонок, с заранее
  подставленным текстом сообщения (свой текст под каждый повод — см. `INTENTS` в `script.js`).
- SEO: title, description, Open Graph для соцсетей, микроразметка Schema.org
  (репетитор, адрес, телефон, часы работы, рейтинг 5,0 и отзывы).
- Доступность: семантическая вёрстка, alt у фотографий, видимый фокус,
  учёт системной настройки «уменьшить движение».
- Шрифты лежат локально — сайт не зависит от доступности Google Fonts из России.
- Внешних запросов нет вообще. Страницы документов печатаются без шапки и подвала.
